# Spotify Clone

A Spotify-style web music player built with HTML, CSS and JavaScript.

**Live demo:** https://spotify-clone-five-orcin.vercel.app

## Features
- Search songs by title or artist
- Player bar with play/pause, next/previous and 10-second skip
- Seek bar with a progress fill, and a volume slider
- Auto-play the next song
- Lock-screen controls on phones (Media Session API)
- Responsive layout for mobile

## Built with
HTML, CSS, JavaScript
